Overview

A headless ASP.NET Core 9 API with a Vue.js + Razor Pages front end that runs a warehouse end to end: sales, purchasing, and stock movements, with reporting.

The back end follows Clean Architecture with CQRS (MediatR) and the Repository pattern. EF Core runs on SQL Server, requests are validated with FluentValidation, logs go through Serilog, and ASP.NET Identity + JWT handles authentication.

Highlights

  • Sales: orders, returns, delivery orders and sales reports
  • Purchase: orders, returns and goods receipt
  • Warehouse: transfers, adjustments, scrapping and stock counts
  • Transaction, stock and movement reports

Request flow

  1. 01

    UI

    Razor Pages + Vue.js call the API with Axios.

  2. 02

    API controller

    JWT-authenticated endpoint dispatches a MediatR command or query.

  3. 03

    Handler

    FluentValidation runs, then the handler applies business rules through repositories.

  4. 04

    Persistence

    EF Core writes to SQL Server; Serilog records the request.
